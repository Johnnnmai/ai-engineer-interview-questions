LLM Fundamentals (Questions 1-20)

Entry1. Explain the transformer architecture at a high level.
Encoder-decoder structure (or decoder-only for modern LLMs). Self-attention allows each token to attend to all others. Layer norm and residual connections stabilize training. FFN layers add non-linearity. Positional encodings provide sequence order information. (Ch. 4)

Mid3. Explain KV cache and why it matters for inference.
During autoregressive generation, key and value matrices from previous tokens are cached to avoid recomputation. Without KV cache, generating each new token would require processing all previous tokens again. Trades memory for compute. Critical for inference speed. (Ch. 4)

RAG / Retrieval (Questions 21-40)

Entry21. Explain the RAG architecture end-to-end.
Ingest: chunk documents, embed chunks, store in vector DB. Query: embed user query, retrieve similar chunks, re-rank, feed to LLM with context. LLM generates an answer grounded in retrieved context. (Ch. 7)

Mid24. How do you implement re-ranking?
After initial retrieval, score each result with a cross-encoder model. Retrieve top 20, re-rank to top 5. Options: Cohere Rerank, BGE Reranker, LLM-based. More expensive but more accurate than embedding similarity alone. (Ch. 7)
